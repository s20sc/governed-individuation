# Supported offline entry point

From the package root run python -B reproducibility/run_offline.py /absolute/new/output using a validated Python3.10.9 or Python3.12.14 runtime. The output directory must be new and outside this immutable package. inputs/research-data.zip is a separately identified research derivative; the original internal archive is not supplied here and must not be substituted under the new filename.

Ten saved-record readers reconstruct the two prospective campaigns, original/blind clause joins, observation classes, retained cue/feedback/frontier comparisons, diagnostic contrasts and120 qualified BEHAVIOR cost cases. Thirteen outputs are byte-exact relative to this derivative's expected files; two use only the original eight-control/twelve-cost numerical contracts. Child readers forbid network and subprocess calls. This is an engineering reanalysis, not independent model/simulator execution or a scientific acceptance verdict. See NUMERICAL-CONTRACTS.md, IMPLEMENTATION-AVAILABILITY.md and the enclosing README for provenance and publication boundaries.

Python3.9.6 is not supported by this complete entry point: its strict feedback comparison differed at two non-whitelisted floating-point leaves. The unchanged numerical contracts reject that run. Other versions beyond the two validated runtimes have not been qualified.
